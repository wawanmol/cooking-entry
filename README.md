Dapur Kilat — a fast, original cooking game set in Warung Bu Kilat. You are the chef: grab ingredients from the pantry crates, chop them on the boards, cook them on the wok burners, assemble each ticket's dish on the plating counter, and serve it at the window before its patience runs out. Five Indonesian dishes combine the same six ingredients in different ways, so every ticket forces a different route through the kitchen; tickets arrive faster and patience shrinks as the 3-minute shift goes on, with a service rush every 70 seconds. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD / arrows to move, E to use a station, click a station to walk to it and use it, P to pause, R to restart.
